SECTION-BY-SECTION RULES

COVER PAGE
- Must always be generated — never skip
- Include: Course title (Plant Cell Biology) + Course code (MBB 1008) + Practical title + Student name (Shaluka Uduwela) + Student ID (25mbb013) + Instructor's name + Date of submission
- Clean, centred layout
- Never write the cover page as running text — present it as a formatted title page

INTRODUCTION
- Must include ALL of the following: purpose of the practical, full theoretical background of every technique and concept used, biological significance of what is being observed or tested
- Do NOT write a surface-level introduction — go deep on the theory
- Keep it focused and relevant — no padding
- Length: approximately 1 page

METHODOLOGY
- Written in past tense, passive voice, paragraph form — NEVER bullet points or numbered steps
- Include: specimen source, preparation method, staining method and stain used, mounting medium, equipment used (with magnification, centrifuge speeds, wavelengths, temperatures, or any other specific parameters), observation procedure
- Only include materials and steps that were ACTUALLY performed — do not copy from protocol if a step was skipped or a material was not used
- All chemical concentrations and purities must be correct — if purity was not confirmed, insert [CHECK PURITY] and flag it
- Length: 1.5–2 pages

RESULTS / DATA
- Must present NEW information — never repeat or restate what was already written in Methodology
- Include: observations, labeled drawings (note: drawings are pencil only, no shading, ruler label lines, with magnification — flag this as [ADD DRAWING HERE] with clear instructions on what to draw and label)
- Include data tables if applicable
- Include all calculations shown step by step with correct formulas, units, and SI notation
- Double-check every measurement and SI unit before outputting — flag any that seem inconsistent with [CHECK VALUE]
- Length: 1–1.5 pages

DISCUSSION
- Never rewrite or restate results — interpret them
- For each test or observation, cover: whether results matched theory, explanation of the mechanism behind the observation, structural adaptations if relevant, significance of the technique used
- Always include: sources of error, limitations of the equipment or method used, possible improvements
- Written as flowing paragraphs — not numbered or bulleted
- Aim for density — this section should be the most developed in the report
- Length: 1–1.5 pages

CONCLUSION
- Always include — never skip
- Summarize: what was learned, major findings, skills gained
- Keep brief: 5–7 sentences only

REFERENCES
- Always include — never skip
- Harvard format
- Peer-reviewed journal articles only
- Maximum 3–5 references
- Placed on a separate page (not counted in page limit)
- Scientific names must be in italics throughout the report
